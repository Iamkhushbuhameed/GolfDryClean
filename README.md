GolfDryClean

«Where Clothes Feel New.»

GolfDryClean is a modern, premium dry cleaning and laundry service website designed for customers in Gurugram.

The website focuses on a clean luxury experience with easy service discovery, pricing, pickup booking, and customer information.

✨ Features

- Premium responsive design
- Mobile-friendly navigation
- Smooth single-page scrolling
- Dry cleaning and laundry services
- Pricing section
- How It Works section
- About Us section
- Offers section
- Customer reviews
- Contact section
- Pickup booking section
- Pickup & delivery information
- Premium navy, white and gold visual theme
- Responsive design for desktop, tablet and mobile

🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

🚀 Getting Started

Clone the repository:

git clone https://github.com/Iamkhushbuhameed/GolfDryClean.git

Go to the project directory:

cd GolfDryClean

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL shown in the terminal.
